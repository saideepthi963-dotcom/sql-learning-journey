# SQL Practice Datasets

This folder contains sample datasets used throughout my SQL learning journey.

## Available Datasets

### Employees Dataset

**File:** `employees.sql`

The employees dataset contains sample employee information for practicing SQL queries.

**Columns:**

- `employee_id` — Unique employee identifier
- `employee_name` — Employee name
- `department` — Department name
- `salary` — Employee salary

## Purpose

These datasets will be used to practice SQL fundamentals, joins, aggregations, subqueries, window functions, and other SQL concepts.

## Database

PostgreSQL
